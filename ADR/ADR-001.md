# ADR-001: اعتماد AIF-PBC-001 v1.0 كخط أساس وبدء التنفيذ التأسيسي

## الحالة
معتمد

## السياق
مشروع AI Foundry وصل إلى مرحلة اعتماد وثيقة إغلاق Phase B (AIF-PBC-001 v1.0) كخط أساس. الوثيقة تحدد 12 شرطاً لإغلاق Phase B، مع فجوات مصدرية مسجلة (DDL، Lock Order، Intent Protocol، آلية الحوكمة، نموذج التهديد، اختبارات T57a/T57b/T35b).

## القرار
1. اعتماد AIF-PBC-001 v1.0 كخط أساس مرجعي للمشروع.
2. بدء التنفيذ التأسيسي (مستودع، هيكل، توثيق، بيئة تطوير) دون انتظار استعادة الوثائق الأصلية.
3. عدم تنفيذ أي منطق يمس الموانع الأربعة (secrets_keys، quota_operations، currency_scale، Lock Order) قبل استعادة مصادرها وفحصها.

## القرارات التقنية الأولية
- **اللغة:** Python للمحرك الأساسي وطبقة الوكلاء. TypeScript لاحقاً لواجهات الإدارة (اختياري).
- **الاستضافة:** محلياً أولاً، مع تجهيز المشروع للنقل إلى VPS نملكه. لا ربط بمنصة مغلقة.
- **الجهاز الحالي:** هاتف Android. التوثيق عبر GitHub Web. التنفيذ لاحقاً عبر Termux أو كمبيوتر.

## حدود التنفيذ التأسيسي
**يمكن البدء الآن:**
- إنشاء المستودع والهيكل.
- كتابة ADR والوثائق.
- إعداد سجل استعادة الوثائق الأصلية.

**لا يمكن البدء قبل المصادر:**
- تنفيذ DDL (الجداول، القيود، الفهارس).
- تنفيذ Lock Order.
- تنفيذ التوقيع (Ed25519/JCS) دون المواصفة.
- تنفيذ UNKNOWN دون Intent Protocol.
- اعتماد أي عقد نهائي.

## التصحيحات الخمسة المعتمدة (مدمجة في نسخة العمل)
1. إحالة 2.2 → 2.4 (معايير الأدلة).
2. فصل أدلة B عن أدلة C في الشروط 8، 9، 10.
3. واجهات أولية مؤقتة غير معتمدة (القسم 8.1).
4. توضيح الإغلاق الآلي: حساب آلي + اعتماد حوكمي (القسم 6).
5. الحد الفاصل بين الشرط 4 (تتبع شامل) والشرط 6 (تمثيل بنيوي).

## الفجوات المصدرية (مسجلة، لا تُملأ بافتراض)
| المصدر | الأثر |
|---|---|
| DDL الأصلي | لا إثبات اكتمال عناصر النموذج (4، 6) |
| Lock Order (31 مستوى) | لا إثبات مطابقة المستويات (7) |
| Intent Protocol | لا إثبات اكتمال المتطلبات (4، 6، 9) |
| آلية الحوكمة/التأسيس | لا إثبات صحة سلطة الاعتماد (3، 5) |
| نموذج التهديد | لا إثبات كفاية نطاق Verifier (10) |
| نصوص T57a/T57b/T35b | لا قرار الضرورة (11) |

## آلية ضبط التغيير
أي تعديل على الوثيقة المرجعية أو هذا القرار يخضع لـ: توثيق السبب، تقييم الأثر، المراجعة، الاعتماد، إدارة الإصدارات.

## النتائج المترتبة
- المستودع هو مصدر الحقيقة.
- كل قرار تقني له مبرر وسجل.
- كل مكون مؤقت يظل موسوماً بأنه مؤقت.
- لا إعلان إنجاز غير مثبت.
